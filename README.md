# quantitative-chiti-kohler-jobin
This repository accompanies the paper "A common quantitative approach to Chiti and Kohler–Jobin inequalities".
In accordance with the disclosure contained in the manuscript, the folder ai-assistance contains the prompt given to ChatGPT 5.6 Sol High and the corresponding raw output used during the exploratory development of the quantitative Kohler–Jobin argument. The final mathematical arguments were subsequently reviewed, corrected, and verified by the authors.
